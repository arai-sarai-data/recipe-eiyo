# レシピ栄養計算

レシピの材料をそのまま貼ると、日本食品標準成分表（八訂）増補2023年の食品に結びつけてグラムに直し、1人分の栄養を計算します。

**サイト：** https://arai-sarai-data.github.io/recipe-eiyo/

- 日本語・English・中文・한국어 に対応（`?lang=en` などで切り替え）。
- 数字はすべて公的機関の公開データから計算しています。出典は各ページに書いています。
- 誤りの訂正・削除のご連絡：arai-sarai-data@proton.me（該当ページのURLと原本の該当箇所を添えてください）
